# HyperExecute Performance Testing

An interactive presentation of performance testing on HyperExecute by TestMu AI (formerly LambdaTest): running JMeter, Gatling and k6 load tests from multiple regions in a single job, with managed load generators and live reports.

Open the live page through GitHub Pages. Add `#existing` to the URL for the version written for current HyperExecute customers, or `#new` for prospects.

Figures come from public TestMu AI pages: JMeter Load Testing, Run Performance Tests at Scale and Stress Testing. Report screens and run numbers are illustrative.
